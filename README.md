# 吐兔卡 Android App

原生 Kotlin / Jetpack Compose 待辦 App，畫面依 `APP.png` 的白底藍色導覽與紅、藍、綠優先級視覺實作。

## 功能

- 行事曆、日期任務列表與筆記
- 任務新增、編輯、刪除、搜尋、分類、標籤與完成紀錄
- 紅、藍、綠優先級圖示一致套用至清單、詳情、通知與 Widget
- AlarmManager 精準提醒、未完成持續提醒、通知完成/延後、開機重建排程
- 小型、中型、大型 Android Widget，可在桌面直接完成任務
- 本機 ZIP 匯出/匯入，可選 AES-256-GCM 密碼加密
- 淺色、深色、跟隨系統、鎖定畫面隱私與系統字體縮放

## 建置

需求：JDK 17、Android SDK 35。

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

可安裝 APK：`outputs/TuTuCard-v1.1.41-debug.apk`（舊版 APK 與 QA 截圖移至 `outputs/archive/`）

桌面小工具可點擊任務名稱、時間及周圍區域開啟內容視窗，按「修改」直接編輯任務，儲存後返回原視窗並更新內容。預覽視窗提供「刪除」，需再次確認後才移除該項目、相關資料及提醒，並更新小工具；取消確認保留原預覽。App 內編輯後保留來源頁面的日期、篩選與列表位置。

小工具每天午夜後自動更新標頭日期與農曆（不喚醒手機，午夜後螢幕亮起即更新），手動調整時間或時區時也會立即更新。小工具清單在關螢幕、離開 App 或每次更新時會自動捲回第一筆，避免標頭日期與畫面項目不一致。三種尺寸的小工具皆使用可上下捲動的完整未完成清單，不再限制只顯示 2、4、5 項。標頭與日期分組皆直接顯示「日期（星期） 農曆日期」，國曆與農曆日期之間一個空格，不顯示「今日」、「待辦事項」或「農曆」兩字，例如「4月16日 (三) 三月十九」。兩種日期合併於同一文字區域，空間不足可換行，與紀錄月曆共用農曆計算。清單名稱與 Checkbox 保留優先顏色，背景與其他文字仍固定為淺色背景、深色文字。小工具挑選預覽同步更新為新排版。

底部分頁依序為「行事曆、任務、筆記、設定」，取消原日曆分頁，以原紀錄月曆移至首頁並更名為行事曆。行事曆中選取日期後按新增任務，預設使用該日期，不會跳回本日；任務分頁或小工具新增仍為目前時間後 10 分鐘。任務與行事曆日期列表的未完成項目，點擊後都先顯示任務預覽，再由編輯按鈕進入修改。儲存後回到原頁面，返回可回到原日期列表。

行事曆由右往左滑切換下個月、由左往右滑切換上個月；點擊上方年月可直接選擇年份及月份，取消不更動原日期。切月保留日期數字，月底超出目標月份時使用該月最後一天。新增任務只允許今天（含）以後，選到過去日期時隱藏新增按鈕。過去日期的任務不分完成狀態皆可預覽及確認刪除，不可修改、勾選完成或延後；資料層及小工具、通知入口同步限制，避免從舊畫面繞過。今天未到設定時間的任務仍不可完成。日期界線依手機當地日期判斷，不影響筆記編輯。

筆記分頁提供新增筆記圖示、標頭及內文搜尋，點選筆記後可直接修改標頭與明細。明細上限 500 個 Unicode 字元，貼上超長內容時只保留前 500 字；顯示即時字數。新增與修改皆需按右上角儲存圖示才寫入資料庫，不再自動儲存；輸入、切到背景及還原草稿皆不寫入筆記資料，未儲存的草稿僅保留在畫面狀態。返回或切換分頁時，如有變更會詢問是否放棄；可繼續編輯。儲存成功返回列表。卡片日期移至標頭上方，格式為「2026/10/19 (一) 10:20 編輯」，新建筆記顯示「建立」，修改儲存才更新編輯時間；未變更內容不更新時間。刪除需再次確認，取消則保留原內容。未輸入任何內容的新空白筆記不會建立紀錄。資料庫維持第 4 版，不清除原任務或筆記。備份包含筆記；匯入不含筆記的舊備份時保留既有筆記。

應用程式內建介面統一繁體中文，包含備份狀態、錯誤訊息與預設備份檔名；日期選擇等程式內系統元件使用繁體中文。使用者輸入的任務、分類、備註及筆記不更動。備份副檔名、內部格式及加密方式保持相容；手機原廠檔案／鈴聲選擇視窗及使用者檔名仍由系統提供。設定頁版本資訊隨實際安裝版本顯示。

筆記編輯頁右上角圖示由左至右為「分享、儲存、刪除」。分享圖示透過系統分享選單選擇 LINE 或其他支援文字分享的應用程式。分享目前編輯欄位的完整標頭與明細（含未儲存內容），兩者以空行分隔，保留原有換行；不截取螢幕、不使用列表省略預覽，也不附加日期。空白筆記不可分享。分享、取消選單或返回筆記皆不儲存、不更新編輯時間，也不宣稱傳送成功。無可用分享程式或系統阻擋時顯示中文提示並保留內容，不新增權限或網路服務。

任務分頁的分類選項與「設定 → 資料 → 分類」共用同一份清單及順序，包含沒有任務的分類；新增、改名及刪除後同步更新。分類篩選使用分類 ID，所選分類被刪除後改為顯示全部。

選擇重複選項不會新增任務；有設定重複的任務，只有確認完成後才會建立一筆未完成的下一期任務。完成狀態、完成紀錄及下一期建立一併寫入，連按同一任務的完成不會重複新增。儲存中禁止重複送出；修改不存在或已完成的任務會拒絕儲存，不會轉成新增。完成確認視窗會顯示任務日期時間。

任務設定的日期時間尚未到時，所有清單、預覽、通知與桌面小工具的 Checkbox 或完成按鈕皆不執行動作、不顯示完成確認，也不建立下一期任務。提前提醒不代表可以提前完成；到達任務日期時間後再次點擊，才會顯示完成確認。資料寫入前會再次檢查日期時間。

過去日期未完成的任務可「補完成」或「移到今天」（保留原時間，已過則改為 10 分鐘後），仍不可修改或延後。重複任務可「跳過這一次」，直接改到下一期且不記為完成；補完成舊的重複任務時，下一期會從今天起算，不會再產生過去日期的任務。設定 → 任務 →「允許提前完成」預設關閉，開啟後未到時間的任務也可勾選完成。

新增任務頁上方提供「快速輸入」，例如「明天下午3點開會」、「星期五繳電費」、「每月5號繳房租」、「每週一 10 點會議」，按「套用」帶入標題、日期、時間與重複，確認後再按儲存；完全在本機解析，不需網路。長按 App 圖示可直接「新增任務」或「新增筆記」。設定頁新增「完成統計」，顯示本週、本月完成率與逾期未完成數。

## 裝置驗收

首次啟動只會顯示通知授權，不會跳離 App 到系統設定頁。無精準鬧鐘權限時會自動使用系統允許的背景提醒方式。通知被滑除不會完成任務，只有「已完成」會停止後續提醒。
