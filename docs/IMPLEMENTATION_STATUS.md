# 吐兔卡實作狀態

## v1.1.41 更新

- 小工具清單捲動後，關螢幕、離開 App、關閉小工具任務視窗或小工具更新時，自動捲回第一筆，避免標頭日期與畫面上的項目不一致。

## v1.1.40 更新

- 修正桌面小工具跨日後標頭日期與農曆不會自動更新，需進入 App 才更新的問題。
- 每次小工具更新時排定下一個午夜的非喚醒鬧鐘，午夜後螢幕亮起即重新整理標頭與清單；不需精準鬧鐘權限。
- 手動調整時間、時區或系統日期變更時也會重新整理小工具。

## v1.1.39 更新

- 過去日期未完成的任務可「補完成」或「移到今天」；移到今天保留原時間，若今天該時間已過則改為現在起 10 分鐘後，並重新排程提醒。過去任務仍不可修改或延後。
- 重複任務可在預覽頁「跳過這一次」，改到下一期，不建立完成紀錄；補完成舊的重複任務時，下一期從今天起算。
- 設定新增「允許提前完成」開關（預設關閉）及「完成統計」（本週、本月完成率與逾期數）。
- 新增任務頁新增中文「快速輸入」，本機解析日期、時間與重複後帶入欄位，需手動儲存才建立。
- 長按 App 圖示提供「新增任務」、「新增筆記」捷徑。
- 新增單元測試：完成／移到今天／跳過規則、快速輸入解析、完成統計。
- 資料庫維持第 4 版，不清除原任務或筆記；備份格式不變。

## v1.1.38 更新

- 行事曆支援左右滑動切月：向左為下個月，向右為上個月；點擊上方年月以轉輪選擇年月，確認才套用，取消保留原月份。
- 切月保留所選日數，超過目標月份天數時取月底；滑動須超過門檻，垂直捲動、短距離拖曳及取消手勢不切月。
- 今天（含）以後可新增，過去日期隱藏新增按鈕，新增／修改的日期選擇器也不可選到過去日期。
- 過去日期的未完成與已完成任務都可查閱及刪除，不可修改、完成或延後。小工具、通知、編輯儲存與資料庫完成／延後更新同步防護，既有任務及筆記資料不清除。
- 日期／時區變動時更新介面日期界線；今天未到時間的任務仍不可完成，重複任務仍僅在有效確認完成後新增下一筆。
- 僅進行原始碼檢查、編譯與 APK 版本／簽章檢查，未啟動測試、模擬器或實機操作。

## v1.1.37 更新

- 筆記編輯頁對調儲存及刪除圖示，右上角由左至右為分享、儲存、刪除。
- 只調整位置，原手動儲存、分享內容及刪除確認行為不變。
- 僅編譯及檢查 APK 版本、簽章，未啟動測試、模擬器或實機操作。

## v1.1.36 更新

- 筆記編輯頁新增分享圖示，以系統文字分享選單選擇 LINE 或其他程式。
- 以目前草稿的完整標頭及明細分享，保留換行，包含未儲存及螢幕外內容，不使用列表省略預覽。
- 空白筆記不可分享，不新增權限、不自動儲存、不更新編輯時間，也不顯示傳送成功。
- 分享無可用程式或遭系統阻擋時提供中文提示，取消或返回後保留原草稿。
- 本版只編譯與檢查 APK 版本及簽章，未啟動 App、測試、模擬器或 LINE 實機分享。

## v1.1.35 更新

- 筆記卡片日期改放在標頭上方，採用完整年月日、中文單字星期及 24 小時時間。
- 新建標記「建立」，修改並儲存後以最新時間標記「編輯」，未更動內容不更新時間。
- 新增及修改使用右上角儲存圖示，取消原有輸入、返回、分頁切換及背景自動儲存。
- 有未儲存變更時返回或切換分頁，提供放棄變更／繼續編輯確認；草稿恢復也不寫入筆記資料。
- 只編譯與檢查 APK 版本及簽章，不執行測試、模擬器或實機操作。

## v1.1.34 更新

- 底部分頁改為行事曆、任務、筆記、設定，原紀錄月曆更名為行事曆並成為首頁，移除原日曆分頁入口。
- 行事曆選取日期後新增任務，預設沿用該日期，原有任務修改不受影響。
- 筆記使用新增筆記圖示；提供標頭、明細、全文搜尋、進入後修改、自動儲存及刪除確認。
- 明細限制 500 個 Unicode 字元，貼上時同樣套用上限，編輯畫面顯示字數。
- 資料庫第 3 至第 4 版只新增 memos 資料表，保留原任務；備份第 4 版納入筆記，舊備份不清除既有筆記。
- 內建介面、錯誤提示、備份說明及預設備份檔名中文化，日期選擇等內部系統元件使用繁體中文；使用者資料及外部系統視窗不改動。版本顯示由已安裝套件讀取。
- 本次只編譯 APK 並檢查封裝簽章，不啟動 App、測試或模擬器。下方第一版驗證紀錄為歷史結果，不代表本版已完成實機驗證。

## 第一版功能

- 月 / 週 / 日檢視、日期切換、任務圓點與當日清單
- 任務新增、編輯、刪除、完成、搜尋與日期 / 分類 / 優先級篩選
- 紅色高優先、淡藍中優先、綠色低優先，套用到 App、通知與 Widget
- 分類、標籤、子任務、備註與完成紀錄
- 每日、每週、每月、每年，以及多週 / 多星期組合的自訂重複
- 準時、預先與自訂分鐘提醒；未完成持續提醒與自訂間隔
- 通知完成、10 / 30 / 60 分鐘延後、自訂延後、滑除後持續提醒
- 開機與 App 更新後重建 AlarmManager 排程
- 小型、中型、大型 Widget，桌面直接完成與新增
- 本機 ZIP 匯出 / 匯入、版本驗證、完整資料還原與排程重建
- 選填密碼的 PBKDF2 + AES-256-GCM 備份加密
- 淺色、深色、跟隨系統、鎖定畫面隱私、TalkBack 描述與系統字體縮放
